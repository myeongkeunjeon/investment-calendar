# 투자 일정 캘린더 (investment-calendar)

S&P 500 기업의 **실적 발표일과 발표 결과**, 미국 연준의 **FOMC 금리 결정일**, **달러/원 환율**을 모아 매일 자동으로 갱신하는 투자 전용 캘린더 웹앱입니다.

- **투자 캘린더 웹앱**: `https://myeongkeunjeon.github.io/investment-calendar/`
  - 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
  - 개인 캘린더와 섞이지 않고 투자 일정만 보여요. (일정 목록 / 달력 / 설정)
  - **설정**에서 S&P 500 종목을 하나씩, 또는 섹터 단위로 켜고 끌 수 있어요. 처음엔 S&P 100(대형주 100개)만 켜져 있어요.
  - **★ 내 종목**: S&P 500 밖의 미국 상장 종목도 검색해서 추가할 수 있고, "★ 내 종목만"으로 모아 볼 수 있어요.
  - **발표 결과**: 발표가 끝난 일정에는 실제 EPS, 시장 예상, 상회/하회 %, 공식 공시(8-K) 링크가 붙어요.
  - 일정 화면 맨 위에 **달러/원 환율**이 나와요. 앱을 열 때마다 최신 값(하나은행 고시 등)을 받아 오고,
    안 되면 유럽중앙은행 기준환율을 보여 줘요. 작은 그래프는 최근 약 2개월 기준환율 추이예요.
  - 달력 탭은 좌우로 밀어서 달을 넘길 수 있어요.
  - 내 종목과 켜고 끈 설정은 그 기기의 브라우저에만 저장되고, 어디에도 전송되지 않아요.
    저장소에는 미국 상장사 **전체**의 공개 실적 일정만 올라가서, 누가 어떤 종목을 골랐는지 알 수 없어요.
- 구독 주소(다른 캘린더 앱용, 선택): `https://myeongkeunjeon.github.io/investment-calendar/calendar.ics`
  (파일 크기 때문에 S&P 100 + FOMC만 들어가요)

각 일정에는 이런 내용이 들어갑니다.
- 한국어 설명: 섹터, 테마, **한국시간 기준 발표 시점**, 대상 분기, 시장 예상 EPS
- 영어 원문 링크: 나스닥 실적 페이지, 연준 FOMC 일정 페이지

공개 정보만 씁니다. 개인 보유 종목 같은 비공개 정보는 넣지 않습니다. 투자 권유가 아닙니다.

## 어떻게 돌아가나요?

```
매일 한국시간 오전 7:17, 밤 11:47 (하루 2번)
  └─ GitHub Actions(깃허브가 빌려주는 컴퓨터)가 자동 실행
       1. 위키백과    → S&P 500 종목 목록(티커·회사명·섹터)과 그중 S&P 100
       2. 나스닥 API  → 지난 100일~앞으로 90일의 확정 실적 발표일과 발표 결과(실제 EPS)
          (달력 표에 결과가 없으면 회사별 '실적 서프라이즈' 표에서 한 번 더 찾아요)
          + 아직 확정 안 된 분기는 '예상일'(🗓️)을 약 6개월 앞까지 계산
       3. 연준 홈페이지 → FOMC 회의 일정 + 최신 점도표(위원 19명의 금리 전망)
          FRED(세인트루이스 연준 통계) → 현재 기준금리, 지난 회의 결정(동결/인하/인상)
       4. Frankfurter API → 달러/원 환율 (유럽중앙은행 기준환율)
       5. 한국어 설명을 붙여 docs/calendar.ics 생성 + 웹앱용 데이터 저장
  └─ GitHub Pages(깃허브의 무료 웹 호스팅)에 올림
  └─ 구독한 캘린더 앱이 새 파일을 읽어 감
```

한 곳에서 가져오기에 실패해도 지난번 데이터를 그대로 써서 캘린더가 비지 않습니다. 지난 일정은 120일 동안 남겨 둡니다.

## 파일 안내

| 파일 | 하는 일 |
|---|---|
| `build_calendar.py` | 캘린더를 만드는 프로그램 |
| `data/themes.json` | 종목별 한국어 테마. **직접 고쳐도 되는 파일**이에요 |
| `data/names_ko.json` | 종목 한글 이름 (한글 검색용). **직접 고쳐도 되는 파일**이에요 |
| `data/sp500.json`, `data/sp100.json` | 마지막으로 가져온 S&P 500 / S&P 100 목록 (자동 저장) |
| `docs/calendar.ics` | 구독용 캘린더 파일 (자동 생성) |
| `docs/events.json` | 일정 기록 (자동 생성) |
| `docs/index.html` | 투자 캘린더 웹앱 (일정·달력·종목 켜고 끄기) |
| `docs/companies.json` | 웹앱 종목 목록 (자동 생성) |
| `docs/market.json` | 미국 상장사 전체 실적 일정 — 내 종목 검색용 (자동 생성) |
| `docs/fx.json` | 달러/원 환율 최근 약 2개월 (자동 생성) |
| `docs/manifest.webmanifest`, `docs/icon*` | 홈 화면 앱 이름·아이콘 |
| `.github/workflows/update-calendar.yml` | 매일 자동 실행 설정 |
| `tests/` | 프로그램이 제대로 동작하는지 확인하는 검사 |

## 처음 한 번만 하는 설정

1. 저장소 **Settings → Pages**로 이동해요.
2. **Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
3. **Actions** 탭 → 왼쪽 **투자 캘린더 갱신** → **Run workflow**를 눌러 첫 실행을 해요.
4. 초록색 체크가 뜨면 위의 구독 주소가 열려요.

## 자주 바꿀 만한 것

- **테마 문구**: `data/themes.json`에서 `"티커": "설명"` 형식으로 고치면 다음 실행부터 반영돼요.
- **조회 기간·발표 시각 추정값**: `build_calendar.py` 맨 위의 `DAYS_AHEAD`, `ESTIMATE_DAYS`(예상일 기간), `PRE_MARKET_ET`, `AFTER_HOURS_ET`를 바꾸면 돼요.
- **실행 시각**: `.github/workflows/update-calendar.yml`의 `cron` 값을 바꿔요. 시간은 UTC 기준이라 한국시간에서 9시간을 빼서 적어요.

## 알아 두면 좋은 점

- 나스닥은 실적 발표를 '장 전/장 후'로만 알려 줘요. 그래서 정확한 시각처럼 보이지 않도록 **시간대**로 보여 줘요.
  - 장 전(📊 … 장 전·저녁): 한국시간 저녁 7:00~9:30 사이 (서머타임이 끝나면 8:00~10:30)
  - 장 후(📊 … 장 후·새벽): 한국시간 다음 날 새벽 5:00~6:00 사이 (서머타임이 끝나면 6:00~7:00)
  - 캘린더에는 한국 날짜의 **종일 일정**으로 들어가요. FOMC만 발표 시각이 정확해서 시간 일정으로 들어가요.
- 시각을 알리지 않은 회사는 미국 날짜에 종일 일정으로 표시돼요.
- 환율: 앱을 열 때 하나은행 고시 환율(두나무 제공, 영업시간 중 약 1분 단위)을 먼저 받아 오고,
  안 되면 ExchangeRate-API, 그것도 안 되면 유럽중앙은행 기준환율(하루 1번)을 보여 줘요.
  어떤 값인지는 환율 아래에 적혀 있어요. 은행 창구·증권사 환전 환율과는 차이가 있을 수 있어요.
- 발표 결과는 나스닥이 결과를 올린 뒤 다음 자동 실행 때 붙어요. 새벽(장 후) 발표는 오전 7:17, 저녁(장 전) 발표는 밤 11:47 실행에서 반영돼요.
  실적은 EPS(주당순이익) 기준이에요. 매출이나 가이던스 같은 내용은 공식 공시(8-K) 링크에서 볼 수 있어요.
- 회사들은 보통 발표 2~5주 전에야 날짜를 확정해요. 그래서 그 뒤 일정은 **🗓️ 예상일**로 보여 줘요.
  직전 발표일에 13주(같은 요일)를 더한 날짜이고, 1~2주 정도 차이 날 수 있어요.
  회사가 날짜를 확정하면 자동으로 **📊 확정 일정**으로 바뀌어요.
- FOMC 일정에는 현재 기준금리, 연준 위원들의 연말 금리 전망(점도표: 지금보다 낮게/같게/높게 본 인원과 중간값),
  시장 확률을 볼 수 있는 CME FedWatch 링크가 붙어요. 지난 회의에는 실제 결정(예: 0.25%p 인하)이 붙어요.
  점도표는 3개월마다(3·6·9·12월 회의) 새로 나와요.
- 구글 캘린더는 구독 캘린더를 보통 12~24시간마다 새로 읽어요. 그래서 바로 반영되지 않을 수 있어요.

```bash
pip install -r requirements.txt
python -m unittest discover tests   # 검사
python build_calendar.py            # 캘린더 만들기
```
